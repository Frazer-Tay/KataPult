# KataPult demo script and submission notes

## Suggested 3-minute demo flow

1. **Home / learning path** - Explain the personal pain point: exam prep was scattered across notes, lists, screenshots, and ad hoc quizzes. KataPult turns it into a structured daily routine.
2. **Vocabulary** - Show example sentence + translation. Message: learners need exam-ready recall, not passive word lists.
3. **Imbuhan / Persamaan** - Show the targeted drills. Message: these are specific Bahasa I2 pain points where repeated retrieval matters.
4. **Flashcards / Custom Test** - Show retention and assessment. Message: the app supports both light review and pressure testing.
5. **PostHog analytics** - Show events for `katapult_Section_Visited`, `katapult_Time_Spent_Section`, and `katapult_Total_Session_Time`. Message: adoption is measurable by person, section, and time spent.

## Strong problem-statement language

Preparing for Bahasa Indonesia I2 was not a lack-of-content problem. It was a practice-system problem. Learners had materials, but they were scattered and passive. The hard parts of the exam - vocabulary recall, imbuhan, persamaan, karangan phrasing, and formal-letter structures - require repeated active retrieval and fast feedback. KataPult was created as the missing medium: a self-serve, bite-sized, modular practice platform that helps learners build readiness in short daily sessions.
